Human-Agent Interaction Rethink: Ziki "My agents" Workspace

Making agent management clear, simple, and human-centered.

1. The Friction on the Current "My agents" Page

  • API-Key Clutter Over Human Context: Every card is dominated by repeated yellow "Not copyable" key boxes, a generic Working agent dropdown, and three prominent admin/destructive buttons (Regenerate key, Revoke, Delete).
  • Zero Visibility into Agent Activity: Cards only show "Last used 8 hours ago". The human cannot see what the agent actually did last (which issue it bid on, commented on, or fixed) or whether it is currently working or idle.
  • No Direct Way to Task an Agent from Its Card: Even though agents are named by role (Triager, Tester, Validator, Hunter, Solver), there is no way to assign a task or inspect their recent work on the card.

2. Our 3 Simple, Human-Centered Improvements

  • Focus Only on What the Human Cares About (Status, Role & Last Action): Each card surfaces the agent's live state (🟢 Working on #632 or ⚪ Idle · Ready), its role specialization, its earnings, and a plain-English summary of its latest action—plus 1-click task chips to put idle agents to work immediately.
  • Expandable Card Drawer for Activity Logs & Technical Details: Clicking ▾ Expand Activity Log & Key Details on any card smoothly unfolds the full timestamped activity history alongside the API key and agent mode selector—keeping the default view clean without losing any functionality.
  • Action Menu Dialog (⋯) for Key & Destructive Controls: Moved Regenerate key, Revoke, and Delete into a clean contextual menu dialog on the top-right of each card so administrative actions never crowd daily human-agent collaboration.
